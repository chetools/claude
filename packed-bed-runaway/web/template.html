Packed-bed reactor: hot spots & runaway

A wall-cooled catalytic tube (o-xylene → phthalic anhydride, Froment's data) modelled in 2D (radial + axial) and solved by the method of lines. The hot spot is mapped against its parametric sensitivity: the Morbidelli–Varma criterion places the runaway boundary where the hot-spot temperature is most sensitive to the inputs. Rust (compiled to WebAssembly) does the fast computing; a Python/numpy/scipy reference confirms it.

The tube is drawn mirrored about its axis (r < 0 is the other half). The hot spot sits on the axis: heat released there has to be conducted across the packing before the coolant can take it away. Drag on a chart to zoom; double-click to reset.

For temperatures the range is in kelvin around the current value (from/to are then offsets, e.g. −25 to +25). With Tc tied to Tin, both move together.

Each pixel is a full 2D solve with the sensitivity s = (p₀/T*)·∂T*/∂p₀ computed by automatic differentiation in the same pass. The white line is the Morbidelli–Varma runaway boundary: for each coolant temperature, the feed at which |s| peaks. Above it (richer feed or hotter coolant) the reactor runs away.

For each S the code sweeps the cooling capacity N (1D: through St; 2D: through ah, with N = 2βah/Da and β = 1/(1/Bi + 1/4)) and takes the N where |s(θ*; N)| is maximal. γ, Da, Bi and am are those of the current inputs, with θw = 0. The derivations are in Theory §9–10.

@@RS_TEST@@

Runs the same case (current sidebar inputs) three ways and compares the results. Rust Rosenbrock is the WebAssembly solver behind the App tab. Python Rosenbrock is pbr.integrate, the same algorithm in numpy, so it should agree to round-off and take the identical steps. scipy BDF is an independent method at a tight tolerance, so it should agree to within the requested tolerance. Sensitivities are compared too: Rust differentiates automatically, Python uses central finite differences.
